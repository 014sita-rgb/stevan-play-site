# Провера на твом Windows рачунару

Ово су изворни код и поступак валидације, **не пробно или завршно издање**.
Локалне тест скрипте не шаљу код на GitHub; API кључеви се не траже у разговору.
Windows репродукција још није извршена у Linux cloud окружењу.

## 1. Развојни алати само за овај тест

За основну проверу потребан је Windows 10/11 x64 са пријављеним корисником
и радном површином. Твој Windows 11 64-bit и постојећи PowerShell 7 су
одговарајући; не инсталирај поново PowerShell. Windows 10 32-bit такође
има x86 test режим, али за развој су потребни одговарајући x86 алати.
Распакуј изворни ZIP у засебну фасциклу, на пример `C:\StevanValidation`.
За компајлирање су потребни:

- [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows).
- [.NET SDK 10.0.401](https://dotnet.microsoft.com/download/dotnet/10.0), тачно као у `global.json`.
- [Node.js](https://nodejs.org/) 22 или новији, само за припрему package-а.
- [NSIS 3.11](https://nsis.sourceforge.io/Download), за инсталер.
- [FFmpeg](https://ffmpeg.org/download.html), доступан као `ffmpeg` у PATH,
  само за синтетички видео који не садржи туђи филм.

Преузимај алате из званичних извора, провери понуђене потписе/checksum-е.
Не искључуј Defender/SmartScreen, проверу TLS-а или execution policy.
Ако организациона политика блокира скрипту, потребан је одобрен поступак,
не `ExecutionPolicy Bypass`. После инсталације алата отвори нови PowerShell 7.
То су развојне зависности за тест; кориснику завршне апликације неће бити
потребни Python, SDK, Node.js, FFmpeg или засебан VLC.

## 2. Аутоматске провере

Из фасцикле у којој је распакован `desktop`, у PowerShell-у 7:

```powershell
./desktop/scripts/test-local-windows.ps1
```

За обе архитектуре на твом Windows 11 x64 и прављење универзалног инсталера:

```powershell
./desktop/scripts/test-local-windows.ps1 -TestBothArchitectures
```

Само x86 процес на x64 или стварном Windows 10 32-bit:
`./desktop/scripts/test-local-windows.ps1 -RuntimeIdentifier win-x86`.
На x86 ОС-у без тог параметра скрипта аутоматски бира x86. Тестирање x86
процеса на x64 (WOW64) није тест 32-bit Windows 10 ОС-а. Windows 11 нема
32-bit издање; ARM64 није део овог пакета.

Ако је NSIS на другој локацији, додај `-MakeNsis 'C:\путања\makensis.exe'`.
Скрипта компајлира, покреће core тестове, прави самосталан пакет и инсталер,
затим заиста покреће Windows native decode, WPF контроле/пун екран/DPAPI и
издвајање звука преко границе од 600 секунди. Кратко ће отварати прозоре;
не користи миш/тастатуру у тест прозору и не закључавај екран док ради.
Провера стаје на првој грешци и не пријављује PASS за пропуштен тест.

Резултати су у `desktop/artifacts/test-results/`, укључујући
`local-windows-validation-win-x64.json` (или `win-x86` /
`both-architectures`), лог, појединачне архитектурне JSON/TRX извештаје и
нормални/fullscreen снимак тест прозора. Прегледај их пре слања: снимци и
лог могу садржати делове радне површине и личне путање. Пошаљи само те
проверене резултате, **не settings датотеке, лозинке или API кључеве**.
`AUTOMATED_CHECKS_PASSED_NOT_A_RELEASE` није потврда готовог производа.

## 3. Оно што мора стварно да се види/чује

Покрени `desktop/artifacts/win-x64/STEVANplejer.exe` искључиво за проверу
(за x86 користи фасциклу `win-x86`).
Отвори `desktop/artifacts/test-fixture/Stevan.Validation.2026.mp4`.
Потврди да видео изгледа исправно, тон се чује, српски титл је видљив и
да пауза, seek, mute, F11/Escape и промене величине раде. Провери и
хрватски/босански локални SRT, 100%/150% DPI, embedded аудио/титл избор.
Забележи Windows верзију и сваки неуспех; приложи снимак само ако је без
личних података. Аутоматски избор subtitle track-а не доказује видљив текст.

У Подешавањима локално унеси сопствене важеће OpenSubtitles/SubDL/Titlovi
налоге/кључеве. Titlovi захтева потврђен e-mail и активиран API приступ.
На законито доступном страном филму/епизоди провери сваку услугу посебно:
српски/хрватски/босански претрага → аутоматски download → видљив титл
→ тачна епизода и време. Пријави назив сервиса, sample-а и исход, без кључа.
Prijevodi извори су тренутно ручне везе; не рачунај их као аутоматски PASS.
За AI је потребна посебна изричита сагласност за cloud upload и могућ трошак.
Без сагласности не покрећи AI; са њом провери превод и синхронизацију
на почетку, средини и крају филма. Лош превод/липсинк је неуспех теста.

## 4. Инсталација и уклањање

Не постављај `CI=true` на свом налогу ради заобилажења заштите у
`test-installer.ps1`. Тај тест је само за изолован CI налог без постојећих
података. На новом засебном Windows тест налогу (или одговарајућој VM)
ручно провери генерисани `*universal-candidate-setup.exe` (или одговарајући
архитектурни инсталер): аутоматски избор x64/x86, инсталацију без admin-а,
Start menu/опционалну Desktop пречицу, репродукцију без Python-а/SDK-а/VLC-а
и нормалну деинсталацију. Подешавања/cache и непознате датотеке морају
остати; не ради uninstall тест над вредним постојећим подацима.
Непотписан локални инсталер може изазвати SmartScreen упозорење; не
проглашавамо га коначним и не тражимо искључивање те заштите.

Све преостале прихватне провере су у [VALIDATION.md](VALIDATION.md).
Скрипта сама не потврђује коначно издање и ништа не објављује.
