## Обавезно пре јавног преузимања APK-а

1. У Android Studio-у отворити горњи изворни пројекат и довршити Gradle синхронизацију.
2. Направити **signed release APK** (Build → Generate Signed Bundle / APK → APK), са *новим, трајним* сопственим release keystore-ом за `rs.stevan.pretrazivac.javni`. Избегавати debug сертификат.
3. Пажљиво и трајно сачувати .jks датотеку и лозинку ван GitHub репозиторијума, са резервним копијама. Све наредне верзије потписују се истим кључем и имају већи `versionCode`.
4. На стварном Android телефону проверити: инсталација, покретање `/play/`, искључиво дугме **ПОШТА** (не **СТЕВАН ПОШТА**), пошта у спољном прегледачу, остале картице, гласовна претрага само на захтев, дугме назад, без дељења сесије и лозинки.
5. Потврђени APK поставити на GitHub репозиторијум у `aplikacije/stevan-pretrazivac-javni/STEVAN_Pretrazivac_JAVNI_1_0_0.apk`. Ово је **планирана путања**, а не тренутно постојећи фајл.
6. Обрачунати SHA-256 APK-а и SHA-256 сертификата, потврдити 200 OK на стварној APK URL адреси и да преузета датотека има исти SHA-256.
7. Тек тада додати у `katalog/catalog.json` **enabled:true** Android APK запис са стварним `apkUrl`, `sha256`, `signerSha256`, `packageName`, `versionCode`, `versionName`. Проверити STEVAN Play Android апликацију, која чита каталог, да подржава нову ставку и покреће системски инсталер.
